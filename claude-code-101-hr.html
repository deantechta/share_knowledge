폴더 = 프로젝트

Claude Code를 사용하는 기본 단위는 폴더(디렉토리)입니다.

  • 1
    작업용 폴더 만들기
    예: "3월_설문취합", "온보딩_패키지"
  • 2
    필요한 파일 모두 넣기
    엑셀, PDF, 텍스트 파일 등
  • 3
    그 폴더를 Claude Code에 지정
    폴더 안 모든 파일을 자동으로 읽음
  • 4
    작업 지시
    "이 파일들을 분석해서 하나로 합쳐줘"

코드 전에 README 먼저

왜 README가 먼저인가?

나중에 도구가 어떻게 돌아가는지 잊어버립니다.
새 동료가 인수인계 받을 때 막막해집니다.

Claude에게 README 먼저 써달라고 하면
작업 시작 전에 설계도가 생깁니다.
프롬프트 "코드 작성 전에 먼저 README.md를 만들어줘. 이 도구가 뭘 하는지, 어떻게 쓰는지, 파일 구조가 어떻게 되는지 포함해서."

실습 준비 · 5분

라이브러리 설치

Claude Code에게 아래처럼 말하면 알아서 설치해줍니다.

Claude Code 프롬프트 "pandas, openpyxl, pdfplumber, glob 라이브러리를 설치해줘"
pandas 엑셀·CSV 읽기, 데이터 정리, 병합 엑셀 자동화
openpyxl Excel 파일(.xlsx) 직접 읽기·쓰기 엑셀 저장
pdfplumber PDF에서 텍스트·표 자동 추출 계약서 분석
glob / pathlib 폴더 안 여러 파일 한 번에 탐색 파일 관리
실습 ① · 30분

내 고통을 글로 씁니다

먼저 해결하고 싶은 업무 고통을 자유롭게 적습니다. AI 용어 몰라도 됩니다.

✍️ 예시 — 내 업무 고통 메모

"매주 팀별 엑셀 파일 3개를 받아서 하나로 합쳐야 하는데 항상 시간이 걸린다. 이름 형식도 제각각이고 빈 칸도 있다. 자동으로 하나로 합치고 싶다."

Claude에게 전달하는 프롬프트 "내 업무 니즈를 쭉 적었는데, 이걸 웹도구로 구현하고 싶어. AI에게 전달할 수 있는 도구 기획서(PRD)로 만들어줘."
PRD = AI가 알아듣는 기획서

내 말: "버튼 눌러서 켜고 끄게 해줘"
PRD에서: "토글 스위치로 on/off 제어"

AI가 모호한 표현을 기술 언어로 번역해줍니다.
이게 내 도구의 스펙이 됩니다

PRD를 그대로 Claude에게 전달하면
그게 구현 지시서가 됩니다.
나중에 수정·업그레이드 요청도 같은 방식으로 합니다.
