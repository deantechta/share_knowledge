## 이전 제작 과정 (v1.0 ~ v2.0)

### 1단계 — 요청 (최초 프롬프트)

```
2시간 세션이 가능한 클로드 코드 사용법 101 교안에 대해 아름다운 비주얼로 만들어줘.
청중은 클로드 코드에 대해 사용 경험이 거의 없고, 컴퓨터에 설치만 되어 있는 사람들이야.
HR과 Workplace Operation 관련 업무를 하고 있어.
```

**포함된 맥락:**
- 청중: HR/WO팀, 코딩 경험 없음
- 왜 파괴적인지 + 무엇을 할 수 있는지 + 어떻게 준비하는지 위주
- 참고 파일: `Claude_Code_12주_교육_프로그램.md`
- 활용 예시는 워크플로우 중심으로 (개발 지식 빼기)

### 2단계 — AI 인터뷰 (5라운드)

정보가 부족해 Claude가 먼저 인터뷰를 진행했다.

#### Round 1 (Q1–Q5)
- 엑셀 3파일 병합 작업 구체화 (인원명부 + 휴가 + 근태, 사번 key)
- 실제 고통 포인트 (10분 × 52주)
- 데이터 클렌징 도구의 탄생 배경
- PRD 인터뷰 방식 확인
- README/CHANGELOG 패턴 여부

#### Round 2 (Q6–Q10)
- 근태/휴가 분석 프롬프트 구체화
- datacleansing HTML 코드 공유
- PRD 구조 기억 확인
- CHANGELOG 버전 이력 (v0.1~v0.4)
- 중점 강조 → **워크플로우 4번 (웹 도구 제작)**

#### Round 3 (Q11–Q15)
- 3파일 분석 스펙 확정 (사번 key, JOIN)
- 실습 도구 후보 논의
- PRD = 완성 HTML 스펙 포함하는 기획서
- 프롬프팅 패턴
- 핵심 메시지: **"이거 될까? → 일단 시켜보라"**

#### Round 4 (Q16–Q19)
- 실습 도구 선택: B(설문분류기) + D(파일명변경)
- PRD 결과물 = 완성된 단일 HTML 파일
- 워크플로우 순서 최종 확정
- 충격 포인트: 001~100 파일명 일괄 변경 + 병합

#### Round 5 (Q20–Q23)
- 워크플로우 순서 재확인
- WF4 핵심 충격: PRD→HTML 즉시 빌드 + 오류 자기 수정
- 오류 처리 슬라이드 포함 요청
- 별도 배포 파일 불필요
