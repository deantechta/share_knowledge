## 1단계 — 요청 (최초 프롬프트)

```
2시간 세션이 가능한 클로드 코드 사용법 101 교안에 대해 아름다운 비주얼로 만들어줘.
청중은 클로드 코드에 대해 사용 경험이 거의 없고, 컴퓨터에 설치만 되어 있는 사람들이야.

```

**포함된 맥락:**

## 2단계 — AI 인터뷰 (5라운드)

- 엑셀 3파일 병합 작업 구체화 (인원명부 + 휴가 + 근태, 사번 key)
- 실제 고통 포인트 (10분 × 52주)
- 데이터 클렌징 도구의 탄생 배경
- PRD 인터뷰 방식 확인
- README/CHANGELOG 패턴 여부

### Round 2 (Q6–Q10)
- 근태/휴가 분석 프롬프트 구체화
- datacleansing HTML 코드 공유
- PRD 구조 기억 확인
- CHANGELOG 버전 이력 (v0.1~v0.4)
- 중점 강조 → **워크플로우 4번 (웹 도구 제작)**

### Round 3 (Q11–Q15)
- 3파일 분석 스펙 확정 (사번 key, JOIN)
- 실습 도구 후보 논의
- PRD = 완성 HTML 스펙 포함하는 기획서
- 프롬프팅 패턴
- 핵심 메시지: **"이거 될까? → 일단 시켜보라"**

### Round 4 (Q16–Q19)
- 실습 도구 선택: B(설문분류기) + D(파일명변경)
- PRD 결과물 = 완성된 단일 HTML 파일
- 워크플로우 순서 최종 확정
- 충격 포인트: 001~100 파일명 일괄 변경 + 병합

### Round 5 (Q20–Q23)
- 워크플로우 순서 재확인
- WF4 핵심 충격: PRD→HTML 즉시 빌드 + 오류 자기 수정
- 오류 처리 슬라이드 포함 요청
- 별도 배포 파일 불필요

## 4단계 — 네비게이션 버그 수정

**증상:** 이전 슬라이드 버튼이 작동 안 함
**원인:** `goToSlide()` 내 `cur`가 setTimeout 콜백 실행 전에 이미 업데이트되어, 콜백이 wrong 슬라이드의 스타일을 정리하는 클로저 문제

**수정 내용:**
```javascript
function goToSlide(n) {
  var oldIdx = cur;   // ← 변수로 캡처 (핵심)
  var newIdx = n;
  var dir = newIdx > oldIdx ? 1 : -1;

  slides[oldIdx].classList.remove('active');
  // ... 퇴장 애니메이션

  slides[newIdx].style.transition = 'none';
  slides[newIdx].classList.add('active');
  void slides[newIdx].getBoundingClientRect(); // ← 리플로우 강제
  // ... 진입 애니메이션

  setTimeout(function() {
    slides[oldIdx].style.transition = '';  // ← oldIdx 사용 (버그 수정)
    slides[newIdx].style.transition = '';
  }, 450);

  cur = newIdx;  // ← setTimeout 이후에 업데이트
}
```

## 핵심 프롬프팅 패턴 (이 작업에서 사용)

### 1. 인터뷰 요청
```
정보가 부족한게 많을 거야.
컨텐츠에 대해서 특히, 부족한 부분은 나를 인터뷰 하고
스킬에 따라 시각화 시작
```
→ Claude가 5라운드 인터뷰를 통해 충분한 맥락을 먼저 수집

### 2. 범위 조정
```
토큰을 무한정 쓰지 말고 작업 안되면 안된다고 말해줘
```
→ 한계 발생 시 솔직하게 말하고 범위를 조정

### 3. 순차 작업
```
뒤로가기 에러를 먼저 해결해줘
```
→ 버그 → 확장 순서로 우선순위 분리

### 4. 점진적 확장
```
워크플로우 1번과 4번을 훨씬 더 상세하고 풍부하게 확장하고 싶어.
이를 위해 필요한 내용을 내게 최소 5턴 인터뷰 진행하고 슬라이드에 반영해서 확장해
```
→ 전체 재작성 대신 특정 부분만 집중 확장

### 5. 메타 문서화 (이 문서)
```
이 슬라이드를 만들었던 과정도 처음부터 끝까지,
현재 대화 맥락을 요약해서 슬라이드 워크플로우라는 마크다운 문서를
현재 경로에 만들어봐 (이 프롬프팅으로 마무리한 거 포함해서)
```
→ 작업 후 프로세스 자체를 문서로 남겨 재현 가능하게
