폴더 = 프로젝트

Claude Code를 사용하는 기본 단위는 폴더(디렉토리)입니다.

  • 1
    작업용 폴더 만들기
    예: "3월_설문취합", "온보딩_패키지"
  • 2
    필요한 파일 모두 넣기
    엑셀, PDF, 텍스트 파일 등
  • 3
    그 폴더를 Claude Code에 지정
    폴더 안 모든 파일을 자동으로 읽음
  • 4
    작업 지시
    "이 파일들을 분석해서 하나로 합쳐줘"

워크플로우 ① · 실제 대화 흐름

Claude Code와 이렇게 대화합니다

1
나 "폴더에 인원명부·휴가·근태 엑셀 3개 넣었어. 사번 기준으로 합치고 싶어. 필요한 정보 인터뷰해줘."
Claude "① 사번 컬럼명이 파일마다 동일한가요? ② 결과는 엑셀로 받을까요? ③ 자동 실행 주기가 있나요?"
2
나 "컬럼명은 '사원번호'로 동일해. 결과는 엑셀로. 매주 월요일에 실행할거야."
Claude "이렇게 진행할게요 → ① 3파일 로드 → ② 사원번호 기준 병합 → ③ 전체_인사현황.xlsx 저장 → ④ README 작성. 진행할까요?"
3
나 "좋아, 실행해줘."
Claude "merge_hr.py, 전체_인사현황.xlsx, README.md 생성 완료했습니다."
4
나 "결과 봤어. 연차잔여일이 0인 사람은 빨간 배경으로 표시해줘."
Claude "v1.1 업데이트 완료. 연차잔여일 0인 행 빨간색 강조 적용했습니다."
5
나 "완벽해. 팀원도 쓸 수 있게 슬랙 공유 메시지 초안도 써줘."
패턴 요약: 인터뷰 요청 → 답변 → 계획 확인 → 실행 → 보완

왜 README가 먼저인가?

나중에 도구가 어떻게 돌아가는지 잊어버립니다.
새 동료가 인수인계 받을 때 막막해집니다.

Claude에게 README 먼저 써달라고 하면
작업 시작 전에 설계도가 생깁니다.
프롬프트 "코드 작성 전에 먼저 README.md를 만들어줘. 이 도구가 뭘 하는지, 어떻게 쓰는지, 개요를 포함하고 이 파일의 변경이력을 추적할 수 있는 Changelog도 넣어줘."

🔢 복수선택 집계

"A, B, C" 형식을 각 항목별 집계로 변환

Claude Code가 하는 일

  • ✅
    주관식 자동 분류
    유사 응답 키워드 추출 후 카테고리 자동 배정
  • ✅
    복수선택 분리·집계
    "A, B" → A: 1회, B: 1회로 자동 카운트
  • ✅
    이상값 탐지
    중복 응답, 범위 벗어난 값 자동 플래그
프롬프트 예시 "주관식 응답을 5개 카테고리로 자동 분류해줘. 유사한 의미는 같은 카테고리로 묶고, 각 카테고리별 빈도를 엑셀로 정리해줘. 복수선택 항목은 쉼표 기준으로 분리해서 각 항목별 집계도 만들어줘."

실패 사례와 해결법

흔한 실수 Top 5

❌
실수 1: 한 번에 너무 많이 요구
해결: 단계별로 나눠서 요청. "일단 기본 기능만 먼저"
❌
실수 2: 오류 나면 바로 포기
해결: 오류 화면 캡처 → "이 오류 해결해줘" 반복. 3-4번은 시도
❌
실수 3: 맥락 없이 요구
해결: "이 파일들이 뭔지 먼저 파악하고 알려줘" 먼저 요청
❌
실수 4: 중간 결과 확인 안 함
해결: 각 단계마다 결과 확인 후 진행. 방향 틀어지면 바로 수정
❌
실수 5: 완벽주의
해결: v0.1부터 시작. 쓰면서 개선. "처음엔 단순해도 괜찮아"
핵심 원칙: "될까?"가 아니라 "일단 시켜보자". 막혀도 멈추지 말고 계속 던지면 해결됩니다.
